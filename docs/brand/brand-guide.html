The channel name

The title bar reads #agentctl — a hash-prefixed channel name, like IRC. Your agent fleet is the channel. The agents are the users.

Agents as nicks

Agent names in angle brackets, color-coded by state: green for idle/done, amber for working, red for blocked. The same visual language as IRC nicks colored by role — ops, voice, regular. Except here the roles are agent states.

[W:2 I:1 B:1]

The status bar

BitchX showed [O/35 N/128 I/4 V/0 F/0] for channel stats. We show [W:2 I:1 B:1] — Working, Idle, Blocked. Same format, same energy, different century.

The prompt wordmark

The wordmark IS a terminal prompt. Dollar sign, command name, blinking cursor. The ghost "dispatch" hints at what happens next. It's not a logo — it's what you type.

Show HN: agentctl – a tmux command center for autonomous coding agents

Show HN Opening Comment
I missed BitchX. I missed status bars that told me everything at a glance, keybindings burned into muscle memory, my terminal as my whole world.

So I built agentctl — a tmux-native command center that manages a fleet of Claude Code agents. Each agent runs in its own tmux window. A background monitor watches them all: spinners when they're working, pause icons when they need approval, clean names when they're done. You dispatch GitHub issues to agents and they ship PRs autonomously — isolated worktrees, their own branches, no conflicts.

The key insight was that tmux already is an agent runtime. Process isolation, session persistence, observability (capture-pane), remote control (send-keys), an event system — it's all there. I just needed to build the orchestration layer on top.

A full autonomous coding task — read the codebase, implement a feature, write tests, commit, push, open a PR — costs about $0.50 with prompt caching on Sonnet.

Single Go binary. No containers, no daemon, no config files to write.
Personal, technical, concrete. Leads with nostalgia, delivers with numbers.
05
Usage
Do Always lowercase: agentctl
Square borders only — no rounded corners
Icon always on dark background (#08090c)
State colors always green → amber → red
JetBrains Mono for everything
Sharp corners, hard edges, no drop shadows
Don't Don't capitalize: AgentCtl, Agentctl, AGENTCTL
Don't round the icon corners
Don't use gradients on the wordmark
Don't put the icon on light backgrounds
Don't add glows, shadows, or 3D effects
Don't use the icon below 32px
